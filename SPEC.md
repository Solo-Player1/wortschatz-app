# Wortschatz (كلماتي) — Technical Spec

German A1 vocabulary trainer for Android (Capacitor WebView). Vanilla HTML/CSS/JS (ES modules, **no bundler, no framework, no external network at runtime**). Two users (Abdullah + a friend), RTL Arabic UI written in **Egyptian colloquial Arabic** (same tone as the existing exam pages: «ابدأ المذاكرة», «ورّيني أخطائي», «خد بالك»). Data = DW "Nicos Weg A1" lessons 1–15 (341 words with original DW audio).

Goal: he opens it instead of Facebook. It must be smooth, pretty, gamified (XP, streak, daily goal), and make memorising words fun. Light + dark mode.

## Data shapes (`www/data/lessons.json`)

```js
{ version, source,
  lessons: [{ n:1, id:"37942133", title:"Hallo!", goal:"التحيّات", gram:"الصيغة الرسميّة…", gramPages:[...], url, exercises:8, words:["37821514", ...] }],
  words:   [{ id:"37821514", de:"auch", ar:"أيضاً", sub:"", audio:"https://…mp3", file:"BAKU_A1_auch.mp3",
              k:"word"|"noun"|"verb"|"phrase", lessons:[1], 
              // nouns only:
              art:"das", sg:"Beispiel", pl:"die Beispiele" /* may be "" = no plural */ }] }
```
Word `id` is stable forever (DW id) — all progress is keyed by it. `de` for nouns is the DW headword "das Beispiel, die Beispiele" — use `displayDe(word)` from data.js to show "das Beispiel".

Nouns: 125, words: 99, phrases: 88, verbs: 29. A word can belong to several lessons.

## SRS rules (`js/srs.js`) — implement exactly

```js
INTERVALS = [0, 1, 3, 7, 14, 30, 60]       // days to add per box 0..6
getState(id) → progress record or default {box:0,due:0,seen:0,ok:0,bad:0,last:0}
isSeen(id)      → seen > 0
isLearned(id)   → box >= 1        ("اتعلمتها")
isKnown(id)     → box >= 2        ("عارفها")
isMastered(id)  → box >= 4        ("ثابتة")
stage(id) → 'new' | 'learning' (box 0-1) | 'known' (2-3) | 'mastered' (4+)
dueWords(lessonN?) → words with progress && due <= todayIndex(), sorted due asc, then box asc
newWords(limit, lessonN?) → unseen words in lesson order (lesson n asc, then order inside lesson), limited
grade(id, ok, {early=false, retry=false}) → newState
   // ok && !early: box=min(6,box+1); due=todayIndex()+INTERVALS[box]
   // ok && early : no change to box/due (practice ahead of time)
   // !ok         : box=0; due=todayIndex()
   // always: seen++, ok?ok++:bad++, last=Date.now(); xp: ok ? (retry?5:10) : 0 → store.xp += xp, days[today].xp += xp, days[today].done += 1
   // save store; return {state, xp}
markIntro(id) → seen=1, box=0, due=todayIndex() (word introduced, not yet answered); days[today].new += 1
counts(lessonN?) → { total, new, learning, known, mastered, due }
buildSession({lesson, newLimit=settings.newPerSession, maxReviews=30}) → { items:[{id, type}], newIds:[], reviewIds:[], early:boolean }
   // 1) reviews = dueWords(lesson).slice(0,maxReviews)   2) news = newWords(newLimit, lesson)
   // 3) if reviews+news == 0 → early = true; take 20 words with the smallest due (future) → reviews (graded with early:true)
   // 4) items: reviews first (lightly shuffled), each new word as {type:'intro'} followed 2–3 items later by a check {type:'mcq_de_ar'} for the same id
   // type for reviews via exercises.pickType(word, state)
```
Streak/daily goal: `settings.dailyGoal` counts `days[today].done` (answered items incl. retries? NO: only first attempts). Session completion → `store.bumpStreak()`.

## Exercises (`js/exercises.js`)

```js
TYPES = ['intro','mcq_de_ar','mcq_ar_de','listen','article','plural','type']
pickType(word, state) → type
   // seen==0 → 'intro'
   // box 0-1 → 'mcq_de_ar' | 'mcq_ar_de' (nouns: 30% 'article')
   // box 2-3 → 'listen' | 'mcq_ar_de' | 'article' (nouns) | 'plural' (nouns with pl)
   // box 4+  → 'type' (if settings.typing) 50% else listen/plural/article/mcq_ar_de
   // 'listen' only when word.file exists (always true now)
makeExercise(word, type) → Exercise:
  { type, id, word,
    prompt: { de?:html, ar?:string, audio?:url, translit?:string, hint?:string },
    options?: [{ text:string, isDe:boolean, correct:boolean }],   // 4 options (3 for article/plural), shuffled
    answer?: string,                                              // for 'type': the expected German (nouns: sg; others: de)
    accept?: string[] }                                           // alternative accepted spellings
distractors: same kind first, same lesson first; never equal to the answer text; never two options with identical text; for 'mcq_de_ar' never two options with the same Arabic meaning.
'article': options der/die/das ; 'plural': correct pl + 2 generated wrong plurals (patterns: +e, +en, +n, +s, unchanged, -in→-innen vs -inen) — never a real alternative.
gradeAnswer(ex, answer) → { ok:boolean, correctText:string, note?:string }
   // mcq/article/plural/listen: answer = option index or text
   // type: normalise both (trim, lower, collapse spaces, strip ".!?…", strip leading article if the user typed it); exact → ok;
   //       equal after folding (ä→ae, ö→oe, ü→ue, ß→ss) → ok with note "الكتابة الصح: <de>";
   //       else not ok
makeMatch(words) → { pairs:[{id, de, ar}], left:[{id,text}], right:[{id,text}] }   // 6 pairs, both columns shuffled
```

## Screens (`js/screens.js`)
- **Home**: greeting with name («أهلًا يا عبدالله 👋» / «أهلًا يا بطل»), streak chip 🔥, daily-goal ring (days[today].done / dailyGoal), two stat cards (مستحق للمراجعة N · جاهزة للتعلّم M), big primary «ابدأ المذاكرة» → `#/session`, secondary «لعبة التوصيل» → `#/match`, «اختار درس» → `#/lessons`, last session summary. If goal reached: celebratory line.
- **Lessons**: 15 cards (number, `title` in `.de`, `goal` Arabic, progress bar learned/total, counts) → `#/lesson/n`.
- **Lesson**: header, counts chips, buttons «ذاكر الدرس ده» (`#/session?lesson=n`) «توصيل» (`#/match?lesson=n`), word list: 🔊 button, de with coloured article, ar, translit (small, muted), stage dots. Tapping 🔊 plays; tapping the row expands plural/sub.
- **Stats**: totals (new/learning/known/mastered/total), XP, streak current/best, 8-week activity grid (days with done>0 coloured by intensity), per-lesson bars.
- **Settings**: theme segmented control (فاتح / غامق / النظام) → `applyTheme` + save; daily goal stepper (5–100); new words per session (3–20); typing toggle; autoplay toggle; name input; export (download `wortschatz-backup.json`, also `navigator.share` if available); import (file input → `store.importJSON`); reset (confirm dialog); about line with data version + «المحتوى من DW Nicos Weg».

## Session UI (`js/session.js`)
- `renderSession(root, {lesson})`: build via `srs.buildSession`; top row: ✕ (confirm if >0 answered → back to home), progress bar, XP counter. Card per exercise type:
  - intro: big German headword (coloured article), translit, 🔊 autoplay, «اقلب الكارت» → Arabic + plural + sub; buttons «عارفها» / «لسه» (both call `srs.markIntro`; «لسه» re-queues an extra mcq check later).
  - mcq_de_ar: German + 🔊 (autoplay) → 4 Arabic options.  mcq_ar_de: Arabic → 4 German options (`.de`).
  - listen: only a big 🔊 button (autoplay) + «اسمع تاني» → 4 German options.
  - article: noun without article → three big coloured buttons der/die/das.  plural: noun → 3 options.
  - type: Arabic (+🔊 optional) → text input (LTR, Latin), umlaut bar (ä ö ü ß), «تحقق».
  - Feedback panel slides up: green «صح!» / red «غلط» + correct answer (with 🔊) + note; «متابعة» button (also Enter). Wrong answer → word re-queued 3–5 items later (retry) until correct. Vibrate(30) on wrong.
  - End: results card: ring %, «+N XP», streak line, «كمان جولة» / «الرئيسية»; call `store.bumpStreak()`, set `store.state.lastSession`; `confetti` if ≥ 80%.
- `renderMatch(root, {lesson})`: 6 pairs de/ar (prefer seen words; fallback any), two columns, tap-tap matching, timer, wrong → shake, done → time + «+15 XP» (added to xp/days but NOT to SRS).
- Keyboard: Enter submits / continues. All text Egyptian Arabic. Must work offline.

### `www/data/videos.json` (يتولّد بـ `python tools/fetch_videos.py`)
```json
{ "version": 1, "source": "...", "videos": [
  { "n": 1, "title": "Hallo!", "duration": 81, "poster": "img/posters/L1.webp",
    "video": { "url": "https://tv-download.dw.com/Events/mp4/nicosweg/A1_E0_L1_F1_sd.mp4", "bytes": 7431385, "q": "sd" },
    "vtt": "data/subs/L1.vtt",

```

- البوسترات مدمجة في `www/img/posters/L<n>.webp` (480×270).
- ستايل الـ cues: `video::cue { background: rgba(0,0,0,.7); color:#fff; font: 600 1rem/1.3 var(--font-de,'Inter',sans-serif); }` (الـ VTT اتشال منه بلوك STYLE بتاع DW).

### `www/js/native.js` — غلاف Capacitor (الوحيد اللي يلمس `window.Capacitor`)
- `isNative()` → `!!window.Capacitor?.isNativePlatform?.()`.
- `plugin(name)` → `window.Capacitor?.Plugins?.[name] || null` (الـ plugins المسجّلة: `Filesystem`, `FileTransfer`, `Share`, `SystemBars`). في المتصفح بيرجّع null وكل الدوال بتتصرف بأمان (ستريمنج بس، تصدير بالـ Blob).
- `fileSrc(uri)` → `window.Capacitor.convertFileSrc(uri)`.
- `openExternal(url)` → في الأبلكيشن `window.open(url, '_system')` (Capacitor بيفتح الروابط الخارجية في المتصفح)، في الويب `window.open(url, '_blank', 'noopener')`.
- `shareText(title, text)` / `shareFile(title, fileUri)` عبر `Share` مع fallback `navigator.share` ثم `false`.

### `www/js/video.js` — شاشة الفيديو + التنزيل
- Route جديد: `#/video/:n` (العنوان «فيديو الدرس»، **immersive** زي session). يدخل من كارت الدرس (زرار «🎬 اتفرج على الحلقة» + البوستر) ومن الرئيسية (كارت صغير «حلقة الدرس اللي واقف عنده»).
- `loadVideos()` بيحمّل `data/videos.json` مرة (cache في الموديول) → `VIDEOS.byLesson[n]`.
- `renderVideo(root, {lesson})`: `<video controls playsinline preload="metadata" poster=...>` بعرض الشاشة (16:9)، تحتها: عنوان الحلقة بالألماني `<bdi class="de">` + عنوان الدرس بالعربي + المدة، سويتش «الترجمة الألمانية» (يفعّل/يعطّل الـ `<track>`؛ محفوظ في `settings.videoSub` افتراضي true)، شريط حالة: «🌐 بيتشغّل أونلاين» أو «📱 محفوظ على التليفون»، زرار «⬇ احفظه للمشاهدة من غير نت (12 ميجا)» مع progress bar، و«🗑 امسح» لو محفوظ. أزرار «الدرس» و«الرئيسية». تمارين الدرس ← «🎯 ذاكر كلمات الدرس».
- المصدر: لو الملف محفوظ → `fileSrc(uri)`، غير كده الـ URL المباشر. لو `navigator.onLine === false` ومش محفوظ → كارت «مفيش نت، نزّل الحلقة الأول لما يبقى عندك واي‑فاي».
- أخطاء الفيديو (`error` event) → toast «مش قادر أشغّل الفيديو» + زرار «جرّب تاني».
- **التخزين** (`native.js` + Filesystem/FileTransfer): المجلد `videos/` في `Directory.Data`، اسم الملف `L<n>.mp4`. `downloadVideo(n, onProgress)`:
  1. `Filesystem.mkdir({path:'videos', directory:'DATA', recursive:true})` (تجاهل خطأ "exists").
  2. `Filesystem.getUri({path:'videos/L1.mp4', directory:'DATA'})` → `uri`.
  3. `FileTransfer.addListener('progress', p => onProgress(p.bytes, p.contentLength))` ثم `FileTransfer.downloadFile({url, path: uri, progress:true})`.
  4. بعد النجاح `Filesystem.stat` وتأكد إن `size` ≈ `bytes` (±1%) وإلا امسح وارمي خطأ.
  5. سجّل في `store.state.videos[n] = {uri, bytes, date}` واحفظ. (أضف `videos: {}` للـ state الافتراضي في store.js مع هجرة للنسخ القديمة.)
  - `deleteVideo(n)`، `isDownloaded(n)`، `downloadedBytes()`.
  - في المتصفح (مش native): زرار التنزيل مخفي ويظهر بداله سطر «التنزيل متاح في أبلكيشن الأندرويد».
- **الإعدادات** (قسم جديد «الفيديوهات»): «نزّل كل الحلقات (15 حلقة · ~120 ميجا) — على الواي‑فاي» بتنزيل متسلسل مع progress إجمالي وإمكانية الإلغاء، «امسح كل الفيديوهات المحفوظة (N ميجا)».
- CSS في `www/css/video.css` (تضاف لـ index.html)، كلاسات بادئة `vd-`.

### `www/js/update.js` — فحص التحديثات
- `checkForUpdate({force=false})`: لو مش force ولو آخر فحص (`store.state.updates.lastCheck`) من أقل من 24 ساعة ← يرجّع المخزّن. غير كده `fetch(UPDATE_MANIFEST_URL + '?t=' + Date.now(), {cache:'no-store'})` بـ timeout 8 ثواني (AbortController). المانيفست: `{version, versionCode, apk, notes, date, dataVersion}`. لو `versionCode > VERSION_CODE` → خزّن في `store.state.updates.available = manifest` وإلا `null`. أي خطأ شبكة → تجاهل بصمت (console.info) وارجع null.
- يُستدعى في `boot()` بعد الرسم الأول (`setTimeout(…, 1500)`) ومش بيمنع التشغيل.
- **الرئيسية**: لو `updates.available` → بانر أعلى المحتوى «🆕 إصدار جديد 1.1.0 — <notes>» بزرار «نزّل التحديث» → `openExternal(manifest.apk)` وزرار «لاحقاً» (يخفيه لحد ما يطلع إصدار أجدد: `updates.dismissed = versionCode`).
- **الإعدادات**: سطر «الإصدار 1.0.0 (1)» + زرار «اتحقق من تحديثات» (force) → toast «أنت على آخر إصدار ✅» أو يعرض البانر. ورابط «صفحة التحديثات» (الريبو).
- `store.state.updates = {lastCheck: 0, available: null, dismissed: 0}` (أضفها للـ state الافتراضي مع هجرة).
