# Wortschatz — code map (read this first, then open only the files you need)

> خريطة البرنامج: اقرا الملف ده الأول بدل ما تقرا الكود كله، وبعدين افتح بس الملفات اللي محتاجها.

Android app (Capacitor 8 WebView) for **two Egyptian adults learning German A1** with DW's video course
**"Nicos Weg" A1 — 76 lessons** (DW's lesson 77 is a final-exam page without vocabulary and is intentionally excluded).
Vanilla ES modules, **no bundler, no framework**, offline-first (only online play, video streaming and update checks need
the network). Owner/developer: Abdullah (front-end dev) — talk to him as a developer, in Egyptian Arabic.

## Golden rules
- **UI text = Egyptian colloquial Arabic**, western digits, Egyptian plurals (helpers `nDays`/`nLessons`…).
- **Word glosses in `lessons.json` = DW's own Arabic (MSA)** — never rewrite them. **Sentences / grammar / wfragen /
  verbs in `content/` = Egyptian colloquial** (see `CONTENT_SPEC.md`).
- Content must stay **faithful to the DW lesson** (its words, DW grammar topic, episode dialogue): the learners will be
  tested on DW and on a real A1 exam. German must be 100 % correct.
- **Do not change the lesson exam system** (🏁 3 hearts, wrong answer is asked again) unless Abdullah asks.
- **Never publish** (GitHub release, manifest push, web update) without Abdullah's explicit OK. Never commit unless asked.
- Fetching from DW works **only through the project's Python tools** (`urllib`); the WebFetch tool is blocked for
  learngerman.dw.com — don't try to get around that.
- Scripts that run on the Windows game server must be English/ASCII (its console can't show Arabic).

## Runtime
`app.js` boots: `store.load()` → `loadData()` (lessons.json) → `loadContent()` (content.json) → hash router
`#/<route>/<arg>?params` → `render*()` into `<main id="view">` (each render fills the view and wires its listeners).

| route | renders |
|---|---|
| `#/home` | `screens.renderHome` — hero, **مهمة النهارده** (mastery.mission), **📅 plan card** (plan.js), due card, quick tiles |
| `#/lessons`, `#/lesson/:n` | lesson map / lesson plan (stars, next step, grammar, sentences) |
| `#/session?lesson=n` · `#/match` | SRS study session (session.js) · matching game |
| `#/exam/:n[?kind=crown]` · `#/drill/:n` | 🏁 lesson exam / 👑 crown re-test · sentence drill (exam.js) |
| `#/games` · `#/game/:id?lesson=n` | game hub · one game (games/*) |
| `#/ref/:page` | references: verbs, wwords, alphabet, numbers, grammar (reference.js) |
| `#/video/:n` | episode player + download (video.js) |
| `#/vs` | play with your friend online (online/*) |
| `#/stats` · `#/settings` · `#/library` · `#/lib/:id` | stats & badges · settings · library |

**State** (`store.js`, localStorage key `ws:v1`): `settings` (theme, dailyGoal, newPerSession, typing, autoplay, name,
missionMode `lesson|goal`, notify*, gameSounds, **planOn**, **planTarget** `YYYY-MM-DD`…), `progress[wordId]`
(SRS box/due/seen/ok/bad + typed), `items[itemId]` (sentences/wfragen/verbs results), `exams[n]` (`passed`/`crown` =
**day index**, best, tries), `games`, `days[YYYY-MM-DD]` (done, xp, sessions, new, exams, crowns…), `streak`, `xp`,
`vs`, `videos` (device), `updates` (device). Day math: `today()`, `dayIndex()`, `todayIndex()`, `dateFromIndex()`.

## Data schemas (short)
- **lessons.json** `lessons[]`: `{n, id, title, goal(AR), gram, gramPages[], url, exercises, words:[wordId]}` ·
  `words[]`: `{id (DW id, stable), de, ar (DW MSA), sub, audio (DW url), file, k: noun|verb|word|phrase, art, sg, pl, lessons:[n]}`
- **content.json**: `sentences[] {id s<NN>-<NNN>, lesson, de, ar, kind, focus[], alts[], cloze{word,opts[]}, src episode|authored, words[]}`,
  `wfragen[] {id w<NN>-<NN>, lesson, q (with ___), answer, opts, ar, reply, reply_ar}`, `grammar{n:[{id,h,body,examples[],table}]}`,
  `verbs[] {inf, ar, lesson, type, forms{ich..sie}, note, examples[]}`, `wwords[]`, `alphabet`.
- **videos.json** `videos[] {n, title, duration, poster, video{url,bytes,q}, sub?, vtt?}` (streams from tv-download.dw.com).

## Pipelines (run from `D:\wortschatz-app`; Git Bash: `cd /d/wortschatz-app`, prefix `PYTHONIOENCODING=utf-8`)
**Vocabulary & media from DW**
1. `python tools/extract_dw.py 16-76 [--no-audio]` → lessons.json (+ caches pages; a re-run reads `tools/cache`, no
   network) · `--audio-only` downloads missing mp3s. It repairs DW data glitches: typos via `DE_FIX` / `SUB_FIX` (by DW
   id — add new ones there, never hand-edit lessons.json), RTL-mangled titles (`… Ich habe kein` → title from the
   episode's Video name) and notes (`?Varianten …`), `(Plural)` kept out of `sg`, double spaces, the separable `|` taken
   from Knowledge.name; verbs with markers (`sich …`, `jemandem etwas …`, `(auf etwas) warten`, `etwas ändern`) and bare
   verbs with principal parts in `sub` are classified `k:"verb"`. Re-runs refresh de/sub/k/art/sg/pl, keep ids/ar/audio.
2. `python tools/fetch_subs.py 16-76` → `www/data/subs/L<n>.vtt`.
3. `python tools/build_videos_index.py 16-76 --posters` → `tools/videos_index.json` + posters, then
   `python tools/fetch_videos.py` → `www/data/videos.json`.
4. Arabic-letter pronunciation for new words (style: `tools/TRANSLIT_GUIDE.md`): `python tools/translit_todo.py --count`
   / `<batch>` prints words still missing → write `tools/translit_parts/part_NN.json` → `--merge` fills `translit.json`.

**Practice content** (contract: `CONTENT_SPEC.md`; gold standard `content/L13–L15.json`)
1. `python tools/lesson_pack.py <n> [--vocab]` — DW words, DW grammar topic, episode dialogue, known vocabulary.
2. write `content/L<NN>.json` → `python tools/check_content.py <n>` until 0 ERROR (also checks episode claims).
3. verbs / question words: edit `content/verbs.json` · `content/wwords.json` → `python tools/check_verbs.py` until 0 ERROR.
4. `python tools/build_content.py` → `www/data/content.json` (`MAX_LESSON = 77`; links sentence words to word ids).

**Release** (ask Abdullah first!) — web update: `python tools/web_update.py make --notes "..."` (bumps `WEB_BUILD`,
zips changed `www/` files vs `updates/baseline-3.json`, writes the manifest web entry) → `gh release create web-<n>
dist/www-<n>.zip` → push `updates/manifest.json` (order matters; raw.githubusercontent caches ~5 min). Version label =
`1.<WEB_BUILD>`. APK: `tools/bump_version.py` (**resets WEB_BUILD to 0** — set it back by hand) + `tools/build_apk.cmd`
(JDK/SDK in `C:\Users\abdel\AndroidDev`, keystore in `android/keystore/` — same key or updates won't install).

## Tests
- `node tests/plan.test.mjs` · `node tests/grading.test.mjs` (DW notations in typed answers, no mangled DW entries) —
  fast · `node tests/engine.test.mjs` (≈2–3 min: every word × every exercise type).
- e2e: `python tests/e2e/serve.py 8131` then `bash tests/e2e/run_all.sh` (Edge headless, ≈35 min; every suite prints
  its FAIL lines + a summary, a crash/timeout is reported; see tests/e2e/README.md). `t_lessons.mjs` opens every lesson
  page 1–76 (cards opened, no sideways overflow) + the reference pages — run it after any data change. `t_update`/`t_integ`
  build their expectations from `www/js/version.js`. Each suite has its own Edge debugging port (93xx–94xx).
- `tools/web_update.py` skips `*.tmp`/`*.bak` in `www/`; keep backups in `backups/` (git-ignored), never inside `www/`.
- Content checks: `python tools/check_content.py all` (lessons) · `python tools/check_verbs.py` (verb table: rule-based
  Präsens check of every form, type labels, DW verbs without an entry, `verb:` focus tags, question words).

## Online play
Relay = separate repo **`D:\wortschatz-server`** (GitHub `Solo-Player1/wortschatz-relay`), runs on the office server
as scheduled task `WortschatzGames`, exposed by ngrok; the app reads `wsUrl` from `updates/online.json`. Protocol
host/join/rejoin/game/ping with session-id reconnect (45 s grace). The office server also runs work systems — never
touch those.

## Where to change what
- daily mission / reminders → `mastery.mission()` + `notify.js` · study plan → `plan.js` (+ home card & settings in `screens.js`)
- a game → `games/<id>.js` (+ shared `games/engine.js`, `games/rounds.js`) · exam → `exam.js` (don't change the rules unasked)
- lesson content → `content/L<NN>.json` then build · vocabulary → re-run `extract_dw.py` (never hand-edit lessons.json)
- home / settings / stats UI → `screens.js` + `css/learn.css` · update flow → `update.js` + `UpdaterPlugin.java`
