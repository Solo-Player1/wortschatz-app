# Wortschatz — كلماتي 🇩🇪

أبلكيشن أندرويد لحفظ كلمات الألماني (مستوى A1) من دروس **DW – Nicos Weg** (الدروس 1 إلى 15، 341 كلمة بصوت DW الأصلي).
الفكرة: تفتحه بدل فيسبوك، تذاكر شوية كلمات كل يوم بنظام التكرار المتباعد (SRS)، وتجمع XP وتحافظ على الستريك 🔥.
فيه وضع فاتح وغامق، وبيشتغل أوفلاين تمامًا (مفيش سيرفر ولا حساب).

## شكل المجلدات

```

│  ├─ index.html

│  └─ audio/*.mp3           صوت DW لكل كلمة (~16 ميجا)

│  ├─ extract_dw.py         بيسحب الدروس من موقع DW
│  ├─ build_apk.cmd / build_apk.sh   بناء الـ APK
│  └─ make_keystore.sh      إنشاء مفتاح التوقيع (بيتعمل مرة واحدة بس)
├─ android/        ← مشروع الأندرويد (Capacitor) — القشرة اللي بتعرض www جوه التليفون
│  ├─ keystore/             مفتاح التوقيع + PASSWORD.txt  ⚠️ خد نسخة احتياطية منه
│  └─ keystore.properties   بيانات التوقيع اللي Gradle بيقراها

├─ capacitor.config.json
└─ package.json    ← فيه رقم الإصدار "version"
```

## تشغيله على الكمبيوتر (في المتصفح)

مينفعش تفتح `index.html` مباشرة (الموديولات والـ fetch محتاجين http). شغّل سيرفر صغير:


## بناء الـ APK

### مرة واحدة بس: الأدوات
الأدوات (JDK 21 + Android SDK) بتتسطّب في `C:\Users\abdel\AndroidDev` من غير ما تحتاج Android Studio:

```bash
bash C:/Users/abdel/AndroidDev/install.sh
```

استنى لحد ما آخر سطر في `C:\Users\abdel\AndroidDev\install.log` يبقى `DONE`.

### كل مرة عايز تطلع APK
دبل كليك على **`tools\build_apk.cmd`** (أو من Git Bash: `bash tools/build_apk.sh`).

السكريبت بيعمل كل حاجة لوحده:
1. يكتب `android/local.properties` بمكان الـ SDK.
2. يعمل مفتاح التوقيع لو مش موجود (`android/keystore/wortschatz.jks`).
3. ينسخ `www` جوه مشروع الأندرويد (`npx cap sync android`).
4. يشغّل Gradle: `assembleRelease`.
5. ينسخ الناتج إلى **`dist/Wortschatz-v<الإصدار>.apk`** ويطبع المسار والحجم.

> ⏳ **أول مرة** بتاخد وقت (5–15 دقيقة) لأن Gradle بينزّل نفسه (~150 ميجا) ومكتبات الأندرويد، ولازم إنترنت.
> المرات اللي بعدها دقيقة أو اتنين.

## التثبيت على التليفون

1. انقل الملف `dist/Wortschatz-v1.0.0.apk` للتليفون (كابل USB، أو تليجرام "Saved Messages"، أو Google Drive).
2. افتح الملف من مدير الملفات.
3. أول مرة هيقولك «لا يُسمح بتثبيت تطبيقات من مصادر غير معروفة» → اضغط **الإعدادات** → فعّل **السماح من هذا المصدر** → ارجع واضغط **تثبيت**.
4. لو Play Protect طلع تحذير → **التفاصيل** → **التثبيت على أي حال**. (التحذير عادي لأي تطبيق مش من المتجر.)

## اللي في الأبلكيشن (الإصدار 2 — ليلة 2/11/2026)

- **مهمة النهارده** في الرئيسية: «خلّص الدرس N النهارده» + زرار الخطوة الجاية بالظبط.
- **إتقان الدرس بضمير** — كل درس ليه خطة من 5 خطوات (صفحة الدرس):
  1. ⭐ تحفظ كل الكلمات (مراجعة متباعدة) · 2. ✍️ تكتب كل كلمة صح (الأسماء بأداتها) · 3. 🧱 تكوّن ٨٠٪ من جمل الدرس وتجاوب أسئلة الاستفهام
  4. 🏁 **امتحان الدرس** (الوحش): كل كلمات الدرس + جمل + تصريف — ٣ قلوب بس. لما تنجح الدرس يبقى «خلصان ✓».
  5. 👑 **امتحان التثبيت** بعد ٣ أيام: لو لسه فاكر الدرس ياخد التاج.
- **12 لعبة** بالقلوب والنقط والكومبو (تاب الألعاب): اسمع واكتب 🎧 · der die das 🎯 · الحروف المتلخبطة 🔤 · كوّن الجملة 🧱 · أدوات الاستفهام ❓ · صرّف الفعل 🔁 · الأرقام 🔢 · الحروف الألمانية 🔠 · صح ولا غلط ⚡ · لعبة الذاكرة 🃏 · الكلمة الناقصة 🫧 · مطر الكلمات 🌧️ — كل لعبة تلعبها على درس معيّن أو على اللي ذاكرته أو كل الدروس.
- **المحتوى الجديد** (الدروس 1–15 بس): ~300 جملة بالعربي المصري، أسئلة استفهام، 40 فعل بتصريفهم، أدوات الاستفهام، الحروف والتهجّي، الأرقام لحد 999 999، وشرح مختصر لكل درس.
- **المراجع** (من تاب الدروس): الأفعال وتصريفها، أدوات الاستفهام، الحروف، الأرقام (اكتب أي رقم واسمعه)، شرح الدروس — كله بالصوت.
- **تذكير كل ساعة** (من 10 الصبح لـ 10 بالليل، بيتظبط من الإعدادات) لو مهمة النهارده لسه ما خلصتش — وبيسكت أول ما تخلّصها.
- الصوت: الكلمات بصوت DW الأصلي، والجمل والأرقام والحروف بصوت التليفون الألماني (Google TTS). لو مش شغّال: الإعدادات ← الصوت ← «نزّل الصوت الألماني».
- إحصائيات: مستوى، نجوم، دروس خلصانة، كلمات اتكتبت صح، وزرار «ابعت تقدمك لصاحبك» 😏.

### إضافة محتوى/دروس بعدين (لما تحب تعدّي الـ 15)
1. `python tools/extract_dw.py 16-20` (الكلمات + الصوت) — وزوّد `MAX_LESSON` في `tools/build_content.py`.
2. اكتب `content/L16.json` … بنفس شكل `CONTENT_SPEC.md` (جمل + أسئلة + شرح)، وضيف الأفعال الجديدة في `content/verbs.json`.
3. `python tools/build_content.py --strict` → بيبني `www/data/content.json` ويقولك لو فيه غلطة.
4. `python tools/bump_version.py 1.1.0 --notes "..."` وبعدين `toolsuild_apk.cmd`.

## التحديث من جوه الأبلكيشن (زرار «حدّث»)

من الإصدار 1.1.0: الأبلكيشن بيفحص `updates/manifest.json` على GitHub مرة في اليوم (أو من الإعدادات ← «اتحقق من تحديثات»)، ولو فيه تحديث بيظهر بانر فيه «حدّث دلوقتي».

- **تحديث ملفات (الأغلب):** ألعاب، محتوى، شاشات، صوت، PDF. الزرار بينزّل zip صغير، والأبلكيشن بيفتح من جديد متحدّث على طول، من غير ما تسطّب حاجة. لو النسخة الجديدة ما فتحتش، أول فتحة جاية بترجع لوحدها للنسخة اللي في الـ APK.
  ```bash
  python tools/web_update.py make --notes "إيه اللي اتغيّر"   # بيرفع WEB_BUILD ويعمل dist/www-<n>.zip ويكتب manifest.web
  gh release create web-<n> dist/www-<n>.zip -R Solo-Player1/wortschatz-app --title "Web update <n>"
  git add -A && git commit -m "Web update <n>" && git push       # المانيفست بعد ما الـ release يترفع
  ```
- **إصدار أندرويد جديد** (plugin جديد، صلاحيات، أيقونة): `python tools/bump_version.py 1.2.0 --notes "..."` ← `bash tools/build_apk.sh` ← `gh release create v1.2.0 dist/Wortschatz-v1.2.0.apk` ← push. الزرار ساعتها بينزّل الـ APK ويفتح شاشة التثبيت (أول مرة أندرويد هيطلب «السماح بتثبيت التطبيقات» من Wortschatz).

## فين التقدّم بيتخزن؟

- كل التقدّم (الصناديق، الستريك، الـ XP، الإعدادات) متخزّن **على التليفون نفسه** جوه الأبلكيشن (localStorage) — مفيش سيرفر ولا حساب.
- **نسخة احتياطية:** من الإعدادات → **⬇️ حفظ نسخة** بيفتح قايمة المشاركة بملف `wortschatz-backup.json` — اختار Drive أو ابعته لنفسك على تليجرام/واتساب. و**📂 استرجاع نسخة** بيرجّعه. لو المشاركة مش شغّالة: «📋 انسخ النسخة كنص».
- التحديث بـ APK **موقّع بنفس المفتاح** (`android/keystore/wortschatz.jks`) بيحافظ على كل البيانات.
- لو مسحت الأبلكيشن أو ثبّت نسخة موقّعة بمفتاح تاني → البيانات بتروح (والأندرويد أصلًا هيرفض التثبيت فوق القديم ويقولك "App not installed"). عشان كده:

> ⚠️ **خد نسخة من مجلد `android/keystore/` (الملف `.jks` + `PASSWORD.txt`) في مكان آمن ومتبعتهوش لحد.**
> من غيره مش هتقدر تطلع تحديثات تتثبت فوق النسخة القديمة.
